# Java Programming – Basic Concepts

This project contains simple Java programs demonstrating basic object-oriented programming concepts such as classes, objects, methods, return values, and inheritance.

## Programs Included

### 1. Father – Inheritance

The `Father` class demonstrates basic methods such as `job()`, `hobby()`, and `property()`.

The `Daughter` class extends the `Father` class and inherits all the methods from the parent class.

**Concepts Used:**
- Class and Object
- Methods
- Inheritance
- Method Calling

**Output Screenshot:**

![Father Output](Father_Output.png)


### 2. Daughter – Inheritance

The `Daughter` class extends the `Father` class. The program creates objects of both `Father` and `Daughter` and calls the inherited methods.

**Concepts Used:**
- Single Inheritance
- Parent Class
- Child Class
- Object Creation

**Output Screenshot:**

![Daughter Output](Daughter_Output.png)


### 3. One – Methods and Return Values

The `One` class demonstrates methods with and without return values.

The `add()` method performs addition and displays the result, while the `add1()` method returns the addition result.

**Concepts Used:**
- Class and Object
- Methods
- Parameters
- `void` Method
- Return Value

**Output Screenshot:**

![One Output](One_Output.png)


### 4. Three – Methods and Objects

The `Three` class demonstrates object creation and method calling.

The `add()` method displays the sum directly, while the `add1()` method returns the sum and stores it in a variable.

**Concepts Used:**
- Class and Object
- Method Calling
- Parameters
- Return Value
- Object Reference Variable

**Output Screenshot:**

![Three Output](Three_Output.png)


## Technologies Used

- Java
- JDK
- Command Prompt (CMD)

## Conclusion

These programs provide a basic understanding of Java classes, objects, methods, return values, and inheritance.
